<h1 align="center">¿QUÉ ES UN PROMPT?</h1>

<p align="center">
Un prompt es la información o instrucción que le damos a una IA para guiar su respuesta.
</p>

---

## ¿Qué es?
Es el texto, instrucción o contexto que una persona le da a un modelo de IA para indicar qué necesita, cómo lo quiere y qué tipo de respuesta espera.

- **Dar una instrucción:** Le dice a la IA qué tarea debe realizar.
- **Aporta contexto:** Añadir información para orientar la respuesta.
- **Define el objetivo:** Inidcar el resultado que se busca.
- **Puede pedir formato:** Puede solictar ejemplos, listas, pasos o tono.

---

## ¿Cómo funciona?
El prompt guía al modelo para interpretar la petición y generar una respuesta.

## ¿Para qué sirve?
- **Indicar la tarea:** Puede pedir explicar, resumir, traducir, generar o analizar.
- **Mejorar la precisión:** Mientras más claro sea, mejor será la respuesta.
- **Controlar el formato:** Puede definir longitud, estilo, tono o estructura.
- **Reducir ambigüedad:** Evita respuestas vagas o poco útiles.

> [!NOTE]
> Un buen prompt reduce la confusión y mejora la calidad del resultado.

---

## Ejemplo práctico
Mismo tema, disitinto nivel de claridad.

**Prompt simple:** *"Explicame Python"*
> [!NOTE]
> Python es un lenguaje de programación muy usado por su simplicidad y versatilidad.

**Prompt detallado:** *"Explicame Python para principiantes con ejemplos sencillos."*
> [!NOTE]
> Python es un lenguaje fácil de aprender. Por ejemplo, puedes usarlo para mostrar mostrar mensajes, hacer cálculos o crear automatizaciones básicas.

----

## ¿Qué debe enseñar?
Debe enseñar que la calidad, el contexto y la precisión del prompt influyen directamente en la calidad de la respuesta generada por la IA.

> [!NOTE]
> Un prompt **más claro** produce **respuestas más útiles**.

---

## Características clave
- **Claridad:** La IA entiende mejor instrucciones directas.
- **Contexto:** Más información ayuda a responder mejor.
- **Especificidad:** Detalles concretos mejoran el resultado.
- **Formato esperado:** Se puede pedir ejemplos, pasos o explicaciones simples.
